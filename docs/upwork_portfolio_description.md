## Role

Power BI Developer / BI Analyst (portfolio project)

## Project description

End-to-end Power BI sales analytics solution for a fictional multi-channel retailer, built with synthetic data to show my full delivery process.

**What I delivered**
- Data cleaning pipeline that removes duplicates and test orders, standardises inconsistent names, and corrects totals - with a logged audit trail
- Star-schema data model (sales fact, monthly targets, 5 dimensions) with a proper date table and clean, single-direction relationships
- 78 documented DAX measures: sales, profit and margin, MoM/YoY/YTD growth, target attainment, Top N products and customers, contribution %, repeat customers, discount impact
- 6-page interactive report design: Executive Overview, Sales Trends, Products, Regions, Customers, Profitability & Discounts, with drill-through, tooltips, synced slicers and dynamic titles
- 17 automated data-quality checks plus expected KPI values to verify every number in the report
- Business insights and recommendations written for management

**Questions the dashboard answers**
Are we hitting target? Which regions, channels and products drive growth or drag it down? Which best sellers have weak margins? How much margin do discounts cost? How concentrated is revenue among customers?

**Tools:** Power BI Desktop, DAX, Power Query (M), Python (pandas), Excel/CSV, Git/GitHub
